# Day 14 - End-to-End CI/CD Pipeline

## Project Overview
A beginner-friendly end-to-end CI/CD project using Jenkins, GitHub, Docker, Docker Hub and AWS EC2.

## Architecture
GitHub → Jenkins → Docker → Docker Hub → AWS EC2

## Technologies
- AWS EC2
- Jenkins
- Git and GitHub
- Docker
- Docker Hub
- Python

## Application
A simple Python HTTP application running on port 5000.

## Project Structure
- app/app.py - Python application
- docker/Dockerfile - Docker image instructions

## Deployment
The application is packaged into a Docker image and deployed as a container.

## Project Status
Currently building the end-to-end CI/CD pipeline.
